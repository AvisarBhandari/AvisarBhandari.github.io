ReadVerse — full-stack bookstore platform

A MERN-stack online bookstore with three separate portals — customer storefront, seller dashboard, and admin panel — each with its own permissions, views, and analytics.

React 18 Vite React Router Node.js Express MongoDB / Mongoose JWT Auth Recharts

// screenshots

// what it does

  • Customers browse and search the catalogue, filter by genre, and buy through a cart and wishlist flow, with a bestsellers carousel and live discount deals on the homepage.
  • Sellers get their own dashboard to list books, track revenue, and see sales trends over time, scoped to just their own inventory.
  • Admins have full platform oversight managing every book, user, and seller account, with charted analytics (purchases over time, top-performing titles) and CSV export for user lists.

// architecture

A conventional two-service MERN split: an Express + Mongoose REST API in backend/ handling auth, books, orders and sales; a Vite-powered React app in frontend/ with role-based routing so the same app serves the storefront at /, the seller portal at /seller, and the admin panel at /admin. Auth is handled with JWTs, and role permissions gate which routes and API calls each user can reach.

// why three roles

The interesting part of this project wasn't the CRUD itself it was designing one data model (books, sales, users) that cleanly supports three very different permission levels and dashboards without duplicating logic between them.

No hosted demo. Clone the repo, add a MongoDB URI and JWT secret to a .env file, and run the backend and frontend dev servers — full steps are in the README.
