Nepali food classifier

An end-to-end computer vision project that classifies traditional Nepali dishes using transfer learning on ResNet18, compares two augmentation strategies head-to-head, and ships predictions through both a Streamlit app and a FastAPI endpoint.

Python PyTorch ResNet18 (Transfer Learning) Streamlit FastAPI Docker

// what it does

Given a photo, the model classifies it into one of seven Nepali dishes momo, dal bhat, sel roti, chowmein, thukpa, chatamari, and yomari after resizing to 224×224 and running it through a fine-tuned ResNet18. Predictions are served two ways: a Streamlit web app for quick manual testing, and a FastAPI POST /predict endpoint for programmatic use, both containerized with Docker.

// results

// two models, one architecture

Both models share the same ResNet18 backbone with a frozen feature extractor and a custom classifier head the only difference is how the training data was preprocessed, to isolate exactly how much augmentation helps.

  • Model 0 — basic augmentation: just resize and tensor conversion. Preserves the original data distribution and converges faster, but is more prone to overfitting on a small dataset.
  • Model 1 — strong augmentation: random resized crop, horizontal flip, rotation, and color jitter layered on top. Converges a little slower but generalizes better to real-world variation in lighting, angle, and framing.

// challenges

The dataset was small and had class imbalance across the seven dish categories, which pushed the baseline model toward overfitting and made it generalize poorly to new images. Transfer learning from a pretrained ResNet18, fine-tuning, and the strong-augmentation pipeline above were the main levers used to address that.

// training setup

  • Loss: CrossEntropyLoss
  • Optimizer: Adam, learning rate 1e-3
  • Schedule: 15 epochs, batch size 32
  • Inference: resize to 224×224 → normalize → forward pass through ResNet18 → softmax → argmax for the final class
